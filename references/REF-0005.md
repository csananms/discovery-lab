# REF-0005: QA-AG First Semester 2026 Course Evidence Directory

**Source type:** Local course-material and classroom-record directory

**Source identity:** QA-AG course evidence directory supplied for first-semester 2026 intake.

**Provenance:** Read-only inventory of `qa-ag_1st25.xls_files` supplied on 2026-08-08. Most course artifacts use `1st26` or year `2569` naming; the directory name uses `1st25`. The naming difference is preserved as provenance uncertainty.

**Related experiment:** [EXP-0007: QA-AG Course Evidence Transfer Intake](../experiments/EXP-0007/README.md)

## Scope Boundary

The directory contains course-design materials, quiz materials, generated summaries, and learner-level classroom records. This reference preserves only a de-identified assessment of the directory's evidence classes. It does not transfer source files, student records, contact information, quiz content, or generated reports.

## Sensitivity Boundary

The directory includes learner identifiers, attendance, assessment scores, feedback, questionnaire responses, learner profiles, and individual dashboard examples. These records are excluded from ordinary evidence transfer. Instructor contact details and any personal information are also excluded.

## Selected Evidence

- Course-framework and agenda materials describe a phase-based adaptive-learning and feedback approach that uses assessment, activity, reflection, and instructor review.
- The directory contains course and quiz-design artifacts as well as classroom measurement records. Their coexistence does not demonstrate a valid causal learning model.
- A generated learning-context document uses Evidence Transfer Protocol language and makes confidence claims based on classroom data. It is treated as derived interpretation, not as independent verified evidence.
- A dashboard discussion draft proposes individual-level profiling and risk labeling. It is a design proposal that depends on restricted learner data, not an accepted Discovery Lab pattern.

## Limits

- No learner-level record, feedback text, score, attendance detail, questionnaire response, contact information, or image is transferred.
- No aggregate analysis was performed in this intake.
- Course-material ownership, learner consent, retention basis, and authorization for research use are not established by the supplied directory.
